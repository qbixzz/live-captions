# ซับสดอังกฤษ-ไทย

โปรแกรมขึ้นซับสดระหว่างประชุมหรือสัมภาษณ์ออนไลน์ โปรแกรมฟังเสียงที่ออกจากลำโพงของเครื่อง จึงได้ยินทุกคนใน Zoom, Teams หรือ Meet แล้วขึ้นซับในหน้าต่างเล็กที่ลอยอยู่บนสุด:
- **ภาษาไทยตัวใหญ่สีขาว** (แปลด้วยเครื่อง) และ **ภาษาอังกฤษตัวเล็กสีเทา** อยู่ใต้ภาษาไทย
- **บรรทัดสีเหลือง** ด้านล่างคือประโยคที่กำลังพูดอยู่ ยังไม่จบ

ทุกอย่างประมวลผลในเครื่องนี้บนการ์ดจอ ไม่ส่งเสียงหรือข้อความออกไปไหน:
- **ถอดเสียง:** faster-whisper กับโมเดล Whisper large-v3
- **แปลไทย:** NLLB-200 รุ่น distilled 600M

English: [README.md](README.md) ขั้นตอนติดตั้งละเอียดอยู่ในฉบับภาษาอังกฤษ

## ต้องมีอะไรบ้าง

- **Windows 10 หรือ 11** เพราะดึงเสียงลำโพงผ่าน WASAPI loopback ซึ่งมีแค่บน Windows
- **การ์ดจอ NVIDIA ที่ใช้ CUDA ได้**
  - ทดสอบกับ RTX 4070 (12 GB) ใช้หน่วยความจำการ์ดจอราว 1.3–3 GB การ์ด 6 GB น่าจะพอ
  - ไดรเวอร์ NVIDIA ต้องเป็นรุ่น 570 ขึ้นไป
  - ไม่ต้องลง CUDA toolkit เอง
- **Python 3.11 ขึ้นไป** ใช้ [uv](https://docs.astral.sh/uv/) สะดวกที่สุด
- **พื้นที่ดิสก์** ราว 6 GB สำหรับโมเดล และอีกราว 5 GB สำหรับ PyTorch
- **ffmpeg** ใช้ตอนซ้อมและตอนทดสอบเท่านั้น ติดตั้งด้วย `winget install Gyan.FFmpeg`

## ติดตั้ง

1. ในโฟลเดอร์นี้ รัน `uv sync` จะได้ `.venv` พร้อม PyTorch รุ่น CUDA
   - ถ้ามี Python env อยู่แล้ว ให้สร้างไฟล์ `local.bat` (git ไม่เก็บไฟล์นี้) แล้วใส่บรรทัดนี้:
     `set "LIVE_CAPTIONS_PYTHON=C:\path\to\env\Scripts\python.exe"`
2. ดับเบิลคลิก `download_models.bat` เพื่อโหลดโมเดลราว 5.5 GB ลงโฟลเดอร์ `models\`
   - **ทำไมไม่ใช้ cache ปกติของ Hugging Face:** cache ใช้ symbolic link ซึ่งบน Windows ที่ไม่มีสิทธิ์ admin หรือไม่ได้เปิด Developer Mode จะ error ว่า `WinError 1314`
   - สคริปต์นี้จึงโหลดเป็นไฟล์ธรรมดาลงโฟลเดอร์ (`local_dir`) แทน
3. **ตั้งค่า (ไม่บังคับ):** คัดลอกไฟล์ตัวอย่างแล้วแก้ git ไม่เก็บไฟล์ที่คัดลอก
   - **`config.example.toml` → `config.toml`:** โมเดล ที่เก็บไฟล์อัด ฟอนต์ และค่าอื่น
   - **`terms.example.txt` → `terms.txt`:** ชื่อเฉพาะ คำย่อ และศัพท์ที่จะได้ยินในการประชุม Whisper จะสะกดคำเหล่านี้ถูกบ่อยขึ้นมาก
     - เปลี่ยนรายการตามแต่ละประชุม
     - ไม่ควรเกินราว 100 คำ

## วิธีใช้

| ทำอะไร | วิธี |
|---|---|
| ใช้จริงระหว่างประชุม | ดับเบิลคลิก `start_live_captions.bat` รอราว 15–30 วินาทีให้โหลดโมเดล จนแถบบนสุดขึ้นว่า `ready` |
| ซ้อมก่อน (ไม่ต้องมี Zoom) | ลากไฟล์เสียงหรือวิดีโอมาวางบน `rehearse.bat` โปรแกรมจะเล่นไฟล์แล้วขึ้นซับให้ดู หรือรัน `rehearse.bat <ไฟล์> [วินาทีที่เริ่ม]` |
| ซ้อมแบบตอน present | เปิด PowerPoint แบบ slideshow แล้วรัน `rehearse.bat` ดูว่าซับบังสไลด์ไหม และอ่านทันไหม |

**เมาส์**
- **ย้อนดูข้อความเก่า:** หมุนล้อเมาส์บนหน้าต่าง ซับทั้งหมดตั้งแต่เปิดโปรแกรมยังอยู่
  - ระหว่างย้อนดู ซับใหม่จะไม่ดึงจอลงไปเอง และแถบบนจะขึ้นว่า `scrolled back · End = latest`
  - กด **End** เพื่อกลับไปบรรทัดล่าสุด
- **ปรับขนาด:**
  - ลากขอบขวาเพื่อปรับความกว้าง
  - ลากขอบล่างเพื่อปรับความสูง
  - ลากมุมขวาล่าง (สี่เหลี่ยมเทาเล็ก) เพื่อปรับทั้งสองด้าน
- **ย้ายหน้าต่าง:** ลากที่แถบบน (ตัวหนังสือเล็กสีเทา) หรือบรรทัดสีเหลืองด้านล่าง
- **เลือกข้อความ:** ลากคลุมแล้วกด Ctrl+C เพื่อคัดลอก
- **คลิกขวา:** เปิดเมนูคำสั่งทั้งหมด

**ปุ่ม** (คลิกที่หน้าต่างซับก่อน)
- **R** เริ่ม/หยุดอัด
- **T** ซ่อน/แสดงภาษาอังกฤษ
- **+ / -** ขยาย/ลดตัวอักษร
- **C** โหมดเล็ก เหลือภาษาไทยราว 2 บรรทัด กดอีกครั้งเพื่อกลับ
- **End** กลับไปบรรทัดล่าสุด
- **Space** หยุดชั่วคราว
- **M** ให้ขึ้นซับเสียงเราด้วย ปกติปิดอยู่ บรรทัดของเราจะขึ้นต้นด้วย "(you)"
- **Esc** ปิดโปรแกรม

## ⚠️ สำคัญตอนแชร์จอใน Zoom

- **แชร์เฉพาะหน้าต่าง PowerPoint อย่าแชร์ทั้งจอ** ถ้าแชร์ทั้งจอ ทุกคนในห้องจะเห็นซับด้วย
  - ทดสอบกับ Zoom แล้ว ถ้าแชร์แค่หน้าต่างเดียว หน้าต่างซับจะไม่ติดไปด้วย
- ถ้ามีสองจอ ลากหน้าต่างซับไปไว้จอที่ไม่ได้แชร์ได้

## การอัดเสียง

- **ซับอย่างเดียวไม่บันทึกอะไร** จะบันทึกก็ต่อเมื่อกด **R** และหยุดเมื่อกด R อีกครั้งหรือปิดโปรแกรม
- **ต้องขออนุญาตทุกคนก่อนกด R**
  - การอัดเสียงคนอื่นโดยไม่ได้รับความยินยอมอาจผิดกฎหมาย ทั้งที่เราอยู่และที่เขาอยู่
  - โปรแกรมนี้ไม่ทำให้ Zoom หรือ Teams ขึ้นสัญญาณว่ากำลังอัด ต้องบอกเขาเอง
- ตอนอัด แถบบนสุดจะเป็นสีแดงและขึ้น `● REC` พร้อมเวลา
- ไฟล์อยู่ที่ `sessions\<วันที่-เวลา>\`
  - **audio.wav:** 16 kHz สเตอริโอ **ซ้ายเป็นเสียงฝั่งเขา** (เสียงลำโพง) **ขวาเป็นเสียงไมค์เรา**
  - **captions.txt:** ซับอังกฤษ-ไทยพร้อมเวลานับจากเริ่มอัด
- โฟลเดอร์ `sessions\` อยู่ใน `.gitignore` ไฟล์เสียงจะไม่ถูก commit ขึ้น git

## ความเร็ว (RTX 4070, Whisper large-v3)

- **ภาษาอังกฤษ:** บรรทัดสีเหลืองขึ้นราว 0.3 วินาทีหลังพูด
- **ภาษาไทย:** ขึ้นราว 0.5–1 วินาทีหลังผู้พูดเว้นจังหวะ
- **ความยาวบรรทัด:** จบบรรทัดเมื่อเว้นจังหวะ 0.45 วินาที หรือเมื่อพูดยาวถึง 8 วินาที โดยตัดตรงจุดที่เงียบที่สุด
- **การ์ดจอ:** ใช้ราว 1.3–3 GB

## ข้อจำกัด

- **ภาษาไทยเป็นการแปลด้วยเครื่อง**
  - ได้ใจความแต่ไม่สวย
  - ชื่อเฉพาะหรือชื่อตำแหน่งบางคำแปลตรงตัวจนผิดความหมาย
  - ใช้ดูจับใจความ อย่าใช้อ้างอิง
- **พูดซ้อนกัน:** ถ้าสองคนพูดพร้อมกัน ซับจะรวมเป็นบรรทัดเดียว
- **ไม่แยกชื่อคนพูด:** ตอนนี้แยกได้แค่ "เขา" (เสียงลำโพง) กับ "เรา" (ไมค์ ถ้ากด M)
- **ฟังภาษาอังกฤษเท่านั้น:** ไม่ถอดเสียงพูดภาษาไทย
- **อุปกรณ์เสียง:**
  - ใช้ลำโพงและไมค์ที่เป็น default ของ Windows
  - ถ้าเปลี่ยนหูฟังกลางทาง ให้ปิดแล้วเปิดโปรแกรมใหม่

## ถ้ามีปัญหา

- **ไม่มีซับขึ้น:**
  - ดูหน้าต่างดำ (console) ว่ามีบรรทัด `[audio] speaker output: …` ไหม
  - เสียงประชุมต้องออกทางลำโพงหรือหูฟังที่เป็น default ของ Windows
- **ขึ้นว่า `CUDA is not available`:**
  - อัปเดตไดรเวอร์ NVIDIA
  - ตรวจว่า torch เป็นรุ่น CUDA คือเลขรุ่นลงท้ายด้วย `+cu128`
- **ช้าหรือกระตุก:** ปิดโปรแกรมที่ใช้การ์ดจอหนัก เช่น เกม หรือ OBS ที่ใช้ GPU encoder
- **ทดสอบโดยไม่ต้องมีคน:**
  - `tests\make_sample_audio.ps1` สร้างไฟล์เสียงอังกฤษตัวอย่างด้วยเสียงสังเคราะห์ของ Windows
  - `python -X utf8 tests\test_pipeline.py tests\sample.wav` ทดสอบทั้งระบบแบบไม่มีหน้าต่าง พร้อมวัดเวลา
