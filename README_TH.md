# ซับสดอังกฤษ-ไทย

โปรแกรมขึ้นซับสดระหว่างประชุมหรือสัมภาษณ์ออนไลน์ โปรแกรมฟังเสียงที่ออกจากลำโพงของเครื่อง จึงได้ยินทุกคนใน Zoom, Teams หรือ Meet แล้วขึ้นซับในหน้าต่างเล็กที่ลอยอยู่บนสุด:
- **ภาษาไทยตัวใหญ่** (แปลด้วยเครื่อง) และ **ภาษาอังกฤษตัวเล็ก** อยู่ใต้ภาษาไทย
  - บรรทัดล่าสุดสว่าง บรรทัดเก่าจางลง
- **บรรทัดสีเหลือง** ด้านล่างคือประโยคที่กำลังพูดอยู่ ยังไม่จบ

ทุกอย่างประมวลผลในเครื่องนี้บนการ์ดจอ ไม่ส่งเสียงหรือข้อความออกไปไหน:
- **ถอดเสียง:** faster-whisper กับโมเดล Whisper large-v3
- **แปลไทย:** NLLB-200 รุ่น distilled 600M

English: [README.md](README.md) ขั้นตอนติดตั้งละเอียดอยู่ในฉบับภาษาอังกฤษ

## ต้องมีอะไรบ้าง

- **Windows 10 หรือ 11** เพราะดึงเสียงลำโพงผ่าน WASAPI loopback ซึ่งมีแค่บน Windows
- **การ์ดจอ NVIDIA ที่ใช้ CUDA ได้**
  - ทดสอบกับ RTX 4070 (12 GB) ใช้หน่วยความจำการ์ดจอราว 1.3–3 GB การ์ด 6 GB น่าจะพอ
  - ไดรเวอร์ NVIDIA ต้องเป็นรุ่น 570 ขึ้นไป
  - ไม่ต้องลง CUDA toolkit เอง
- **พื้นที่ดิสก์** ราว 6 GB สำหรับโมเดล และอีกราว 5 GB สำหรับ PyTorch
- **ffmpeg** ใช้ตอนซ้อมเท่านั้น ติดตั้งด้วย `winget install Gyan.FFmpeg`

## ติดตั้ง

### แบบแอป (แนะนำ)

1. โหลด `LiveCaptions-<version>-win64.zip` จากหน้า [Releases](../../releases) ไฟล์ราว 25 MB
2. แตกไฟล์ไว้ในโฟลเดอร์ของเรา เช่น `Documents\LiveCaptions`
   - คลิกขวาที่ zip แล้วเลือก **Extract All**
   - อย่ารันจากใน zip และอย่าวางไว้ใน `Program Files`
3. ดับเบิลคลิก **`Live Captions.exe`** ครั้งแรกจะมีหน้าต่างติดตั้งขึ้นมา:
   - ลง Python แพ็กเกจ และโมเดล รวมราว 10 GB ใช้เวลา 10–30 นาที
   - ตรวจการ์ดจอ
   - เลือกได้ว่าจะเพิ่มทางลัดใน Start menu และบนเดสก์ท็อปไหม
   - ครั้งต่อไปเปิดแอปได้ทันที

**หมายเหตุ:**
- **ติดตั้งค้างหรือหยุดกลางทาง:** เปิดใหม่ได้ ส่วนที่เสร็จแล้วจะข้ามไป
- **ซ่อมการติดตั้ง:** รัน `Live Captions.exe --setup`
- **อัปเดตรุ่นใหม่:** แตกไฟล์ลงโฟลเดอร์ใหม่ ถ้าไม่อยากโหลดโมเดลซ้ำ ให้คัดลอกโฟลเดอร์ `models` จากโฟลเดอร์เดิมมาก่อน
- **ซ้อม:** ลากไฟล์เสียงหรือวิดีโอมาวางบน `Live Captions.exe`
- **ถ้ามีปัญหา:** รายละเอียดอยู่ที่ `logs\live-captions.log`

### จาก source code

1. ติดตั้ง [uv](https://docs.astral.sh/uv/) ถ้ายังไม่มี โดยรันใน PowerShell:
   `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
2. ดับเบิลคลิก **`setup.bat`** โปรแกรมจะทำ 3 อย่าง:
   - ลงแพ็กเกจพร้อม PyTorch รุ่น CUDA
   - ตรวจว่าใช้การ์ดจอได้
   - โหลดโมเดลลงโฟลเดอร์ `models\`
   - รันซ้ำได้ ส่วนที่มีอยู่แล้วจะข้ามไป
3. ดับเบิลคลิก **`start_live_captions.bat`**

**หมายเหตุ:**
- **ทำไมโหลดโมเดลลงโฟลเดอร์ ไม่ใช้ cache ปกติของ Hugging Face:** cache ใช้ symbolic link ซึ่งบน Windows ที่ไม่มีสิทธิ์ admin หรือไม่ได้เปิด Developer Mode จะ error ว่า `WinError 1314` สคริปต์จึงโหลดเป็นไฟล์ธรรมดา (`local_dir`)
- **ถ้ามี Python env อยู่แล้ว** ให้สร้างไฟล์ `local.bat` (git ไม่เก็บไฟล์นี้) แล้วใส่บรรทัดนี้:
  `set "LIVE_CAPTIONS_PYTHON=C:\path\to\env\Scripts\python.exe"`
- **`terms.txt`:** ใส่ชื่อเฉพาะ คำย่อ และศัพท์ที่จะได้ยินในการประชุม Whisper จะสะกดคำเหล่านี้ถูกบ่อยขึ้นมาก
  - `setup.bat` สร้างไฟล์นี้ให้จากตัวอย่าง
  - เปลี่ยนรายการตามแต่ละประชุม ไม่ควรเกินราว 100 คำ
- **ค่าอื่น ๆ:** คัดลอก `config.example.toml` เป็น `config.toml` แล้วแก้ เช่น โมเดล ที่เก็บไฟล์อัด และฟอนต์
- **หน้าต่างจำค่าเอง:** ขนาด ตำแหน่ง ขนาดตัวอักษร ความทึบ การปักหมุด และการแสดงภาษาอังกฤษ เก็บไว้ที่ `%APPDATA%\live-captions\window.json`

## วิธีใช้

| ทำอะไร | วิธี |
|---|---|
| ใช้จริงระหว่างประชุม | ดับเบิลคลิก `start_live_captions.bat` รอราว 15–30 วินาทีให้โหลดโมเดล จนไฟมุมซ้ายบนเป็น **สีเขียว** |
| ซ้อมก่อน (ไม่ต้องมี Zoom) | ลากไฟล์เสียงหรือวิดีโอมาวางบน `rehearse.bat` โปรแกรมจะเล่นไฟล์แล้วขึ้นซับให้ดู |
| ซ้อมแบบตอน present | เปิด PowerPoint แบบ slideshow แล้วรัน `rehearse.bat` ดูว่าซับบังสไลด์ไหม และอ่านทันไหม |

**หน้าต่าง**
- **แถบบน:**
  - **ไฟสถานะ:** สีส้มกำลังโหลด, สีเขียวพร้อมใช้, สีเทาหยุดชั่วคราว, สีแดงมีปัญหา
  - **แถบระดับเสียง:** ขยับเมื่อมีเสียงจากการประชุม ดูได้ทันทีว่าโปรแกรมได้ยินหรือไม่
  - **ป้ายแดง `● REC`:** ขึ้นพร้อมเวลาเมื่อกำลังอัด
- **ปุ่ม:** โผล่บนแถบบนเมื่อเอาเมาส์มาวางบนหน้าต่าง เรียงจากซ้ายไปขวา:
  - **EN** ซ่อน/แสดงภาษาอังกฤษ
  - **ไมค์** ขึ้นซับเสียงเราด้วย
  - **ลด/ขยายตัวอักษร**
  - **โหมดเล็ก**
  - **หยุดชั่วคราว**
  - **อัด**
  - **ปักหมุด** ให้ลอยบนสุดตลอด หรือยอมให้หน้าต่างอื่นบังได้
  - **ช่วยเหลือ**
  - **ย่อหน้าต่าง** ลงแถบงาน คลิกปุ่มบนแถบงานเพื่อเปิดกลับ
  - **ปิด**

  ชี้ที่ปุ่มค้างไว้ จะมีคำอธิบายขึ้นที่แถบบน
- **ย้อนดูข้อความเก่า:** หมุนล้อเมาส์ ระหว่างย้อนดู ซับใหม่จะไม่ดึงจอลงไปเอง กดปุ่ม **↓ Latest** หรือ **End** เพื่อกลับบรรทัดล่าสุด
- **ย้ายหน้าต่าง:** ลากที่แถบบน หรือบรรทัดสีเหลือง
- **ปรับขนาด:** ลากขอบขวา ขอบล่าง หรือมุมขวาล่าง (จุดเล็ก ๆ)
- **เลือกข้อความ:** ลากคลุมแล้วกด Ctrl+C เพื่อคัดลอก
- **คลิกขวา:** เปิดเมนู มีทุกคำสั่งข้างบน และยังมี:
  - ปรับความทึบ
  - เปิด/ปิดการซ่อนจากการแชร์จอ
  - คืนขนาดและตำแหน่งเดิม

**ปุ่มคีย์บอร์ด** (คลิกที่หน้าต่างซับก่อน กด **F1** หรือ **?** เพื่อดูในหน้าต่าง)
- **R R** เริ่มอัด ต้องกด**สองครั้ง** ครั้งแรกจะเตือนให้ขออนุญาตก่อน ส่วนหยุดอัดกด R ครั้งเดียว
- **T** ซ่อน/แสดงภาษาอังกฤษ
- **+ / -** ขยาย/ลดตัวอักษร
- **C** โหมดเล็ก เหลือภาษาไทยราว 2 บรรทัด กดอีกครั้งเพื่อกลับ
- **End** กลับไปบรรทัดล่าสุด
- **Space** หยุดชั่วคราว
- **M** ให้ขึ้นซับเสียงเราด้วย ปกติปิดอยู่ บรรทัดของเราเป็นสีฟ้าและขึ้นต้นด้วย "You ·"
- **P** ปักหมุด/เลิกปักหมุด ให้ลอยบนสุดหรือไม่
- **Esc Esc** ปิดโปรแกรม ต้องกด**สองครั้ง** กันกดพลาดกลางประชุม

## ⚠️ การแชร์จอ

- **หน้าต่างซับถูกซ่อนจากการแชร์จอและภาพหน้าจอเป็นค่าเริ่มต้น**
  - คนในห้องจะไม่เห็นซับ แม้เราแชร์ทั้งจอ
  - ต้องใช้ Windows 10 รุ่น 2004 ขึ้นไป ถ้าใช้ไม่ได้ จะมีข้อความเตือนที่แถบบน
  - ปิดการซ่อนได้ที่เมนูคลิกขวา
- **ถึงอย่างนั้น ถ้าทำได้ ให้แชร์เฉพาะหน้าต่าง PowerPoint** ปลอดภัยที่สุด
  - ก่อนประชุมสำคัญ ให้ลองแชร์จอทดสอบกับโปรแกรมประชุมที่ใช้สักครั้ง
  - ทดสอบกับ Zoom แล้ว ถ้าแชร์แค่หน้าต่างเดียว หน้าต่างซับจะไม่ติดไปด้วย
- ถ้ามีสองจอ ลากหน้าต่างซับไปไว้จอที่ไม่ได้แชร์ได้

## การอัดเสียง

- **ซับอย่างเดียวไม่บันทึกอะไร** จะบันทึกก็ต่อเมื่อกด **R สองครั้ง** และหยุดเมื่อกด R อีกครั้งหรือปิดโปรแกรม
- **ต้องขออนุญาตทุกคนก่อนอัด**
  - การอัดเสียงคนอื่นโดยไม่ได้รับความยินยอมอาจผิดกฎหมาย ทั้งที่เราอยู่และที่เขาอยู่
  - โปรแกรมนี้ไม่ทำให้ Zoom หรือ Teams ขึ้นสัญญาณว่ากำลังอัด ต้องบอกเขาเอง
- ตอนอัด แถบบนจะมีป้ายแดง `● REC` พร้อมเวลา เมื่อหยุด แถบบนจะบอกว่าไฟล์อยู่ที่ไหน
- ไฟล์อยู่ที่ `sessions\<วันที่-เวลา>\`
  - **audio.wav:** 16 kHz สเตอริโอ **ซ้ายเป็นเสียงฝั่งเขา** (เสียงลำโพง) **ขวาเป็นเสียงไมค์เรา**
  - **captions.txt:** ซับอังกฤษ-ไทยพร้อมเวลานับจากเริ่มอัด
- โฟลเดอร์ `sessions\` อยู่ใน `.gitignore` ไฟล์เสียงจะไม่ถูก commit ขึ้น git

## ความเร็ว (RTX 4070, Whisper large-v3)

- **ภาษาอังกฤษ:** บรรทัดสีเหลืองขึ้นราว 0.3 วินาทีหลังพูด
- **ภาษาไทย:** ขึ้นราว 0.5–1 วินาทีหลังผู้พูดเว้นจังหวะ
- **ความยาวบรรทัด:** จบบรรทัดเมื่อเว้นจังหวะ 0.45 วินาที หรือเมื่อพูดยาวถึง 8 วินาที โดยตัดตรงจุดที่เงียบที่สุด
- **การ์ดจอ:** ใช้ราว 1.3–3 GB

## ข้อจำกัด

- **ภาษาไทยเป็นการแปลด้วยเครื่อง**
  - ได้ใจความแต่ไม่สวย
  - ชื่อเฉพาะหรือชื่อตำแหน่งบางคำแปลตรงตัวจนผิดความหมาย
  - ใช้ดูจับใจความ อย่าใช้อ้างอิง
- **พูดซ้อนกัน:** ถ้าสองคนพูดพร้อมกัน ซับจะรวมเป็นบรรทัดเดียว
- **ไม่แยกชื่อคนพูด:** ตอนนี้แยกได้แค่ "เขา" (เสียงลำโพง) กับ "เรา" (ไมค์ ถ้ากด M)
- **ฟังภาษาอังกฤษเท่านั้น:** ไม่ถอดเสียงพูดภาษาไทย
- **อุปกรณ์เสียง:**
  - ใช้ลำโพงและไมค์ที่เป็น default ของ Windows
  - ถ้าเปลี่ยนหูฟังกลางทาง ให้ปิดแล้วเปิดโปรแกรมใหม่

## ถ้ามีปัญหา

- **ไม่มีซับขึ้น:**
  - ดูแถบระดับเสียงที่แถบบน ถ้าไม่ขยับตอนมีคนพูด แปลว่าโปรแกรมไม่ได้ยินเสียงประชุม
  - เสียงประชุมต้องออกทางลำโพงหรือหูฟังที่เป็น default ของ Windows
  - ดูหน้าต่างดำ (console) ว่ามีบรรทัด `[audio] speaker output: …` ไหม
- **ขึ้นว่า `CUDA is not available`:**
  - อัปเดตไดรเวอร์ NVIDIA
  - ตรวจว่า torch เป็นรุ่น CUDA คือเลขรุ่นลงท้ายด้วย `+cu128`
- **ช้าหรือกระตุก:** ปิดโปรแกรมที่ใช้การ์ดจอหนัก เช่น เกม หรือ OBS ที่ใช้ GPU encoder
- **ทดสอบโดยไม่ต้องมีคน:**
  - `tests\make_sample_audio.ps1` สร้างไฟล์เสียงอังกฤษตัวอย่างด้วยเสียงสังเคราะห์ของ Windows
  - `python -X utf8 tests\test_pipeline.py tests\sample.wav` ทดสอบทั้งระบบแบบไม่มีหน้าต่าง พร้อมวัดเวลา
